# ワークスペースを検索

開いているフォルダ内のテキストを、左サイドバーの **検索** から横断検索できます。Markdown に加え、PDF / `.docx` の抽出テキストも対象です。

## 開き方

1. [フォルダを開く](open-project.md)
2. 左サイドバー上部の **検索** タブをクリック（**エクスプローラー** / **アウトライン** の隣）

または **表示 → 検索を表示**、**編集 → フォルダ内を検索**（Ctrl+Shift+F）。フォルダを開くまで検索は使えません。

## 検索モード

| モード | 用途 |
|--------|------|
| **意味** | トピックや言い回しで探す（索引の埋め込み + キーワードのハイブリッド） |
| **文字** | 文言の完全一致に近い検索。置換もこちら |

## 何ができる？

- ワークスペース内のテキスト検索（PDF / `.docx` の抽出テキスト含む）
- ヒットのパス・見出し・スニペット表示 → クリックで該当箇所を開く
- 任意の **置換**（文字モード向け。検索パネル内で開閉）
- 大文字小文字・単語単位・正規表現のマッチオプション（文字モード）
- 含める / 除外する glob で範囲を絞る

## Tips

- 大きなフォルダでは索引や検索に少し時間がかかることがあります
- `node_modules` や `.git` などはエクスプローラーと同様に除外されます
- 見出し一覧だけ見たいときは左の **アウトライン** タブ（Ctrl+Shift+O）

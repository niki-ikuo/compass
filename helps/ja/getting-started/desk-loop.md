# クリップ

外でコピーしたテキストを Compass に集め、下書きして、送り出す前に検品するための流れです。`.compass` フォルダはエクスプローラーに出ません。左サイドバーの **クリップ**、または **表示 → クリップを表示**（`Ctrl+Shift+D`）から開けます。

## 使い方（最短）

1. どこかで文章をコピーする
2. ホットキー（既定: `Ctrl+Alt+I`）で inbox に取り込む
3. クリップで内容を開き、「下書きを作る…」でメール／議事録などを作成する（AI のプレビュー適用）
4. Outbox の **検品してコピー** で問題を確認し、メーラーなどに貼る
5. 使い終わったら **済**（一覧から隠す／アーカイブ）または **削除**

## 設定

設定 → **クリップ** でホットキーの有効／無効・着地後の動作・**閉じたらトレイに常駐** を変更できます。トレイ常駐をオンにすると、ウィンドウを閉じても取込ホットキーが使えます。完全に終了するにはトレイメニューまたは **ファイル → 終了** を使います。
